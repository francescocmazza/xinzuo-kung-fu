La figura del Gyuto utilizza ora il file locale approvato `knife-shapes/Gyuto.jpg`, mentre quella dello spelucchino diritto utilizza il file locale approvato `knife-shapes/B30R-SG.jpg`. La figura del coltello occidentale da disosso rimane un segnaposto editoriale in attesa di una fotografia locale approvata. Vedi `EDITORIAL_REQUIREMENTS.md` per la regola che impedisce il ripetersi di hotlink esterni non approvati.
